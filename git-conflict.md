# Описание конфликта

## Файл: api-plan.md

**Что произошло:**
В ветке `feature/cart` был добавлен раздел «Корзина»,
а в ветке `main` уже был раздел «Каталог» — в одном и том же
месте файла `api-plan.md`.

При выполнении `git merge feature/cart` Git не смог автоматически
объединить изменения и сообщил о конфликте:

    CONFLICT (content): Merge conflict in api-plan.md
    Automatic merge failed; fix conflicts and then commit the result.

**Как исправлено:**
1. Открыла `api-plan.md` в редакторе nano.
2. Увидела маркеры конфликта:
       <<<<<<< HEAD
       ## Каталог
       ...
       =======
       ## Корзина
       ...
       >>>>>>> feature/cart
3. Вручную объединила оба раздела в файле.
4. Удалила все маркеры конфликта (`<<<<<<<`, `=======`, `>>>>>>>`).
5. Сохранила файл.
6. Отметила конфликт разрешённым: `git add api-plan.md`.
7. Сделала отдельный коммит:
       git commit -m "Исправлен конфликт в api-plan.md (Каталог + Корзина)"

**Коммит с исправлением:** `080255d`
